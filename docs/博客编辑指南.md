# 社团官网 · 内容编辑指南

本文面向**社团管理员 / 编辑同学**，介绍如何在不碰代码的前提下，
往网站里**发布新的「社团动态」、编辑已有文章、上传图片**，以及整个站点的目录结构。

> 适用对象：宜昌一中科创社团官网（基于 Hexo 构建，`yckc` 主题）
> 部署方式：写好文章 → `git push` → Vercel 自动构建上线

---

## 一、目录结构总览

仓库里你**只需要关心 `source/` 这一个文件夹**，其余都是构建配置，不要改。

```
clubblog/
├── source/                  ← 【你主要在这里工作】
│   ├── _posts/              ← 社团动态（新闻文章）都在这里，每篇一个 .md
│   │   ├── 2024-08-02-guozui-yidui.md
│   │   ├── 2026-05-18-haonian.md
│   │   └── ……（每篇动态一个文件）
│   ├── about/               ← 社团概况栏目（简介/教师/荣誉/总览）
│   │   ├── index.md  intro.md  teacher.md  honors.md
│   ├── join/                ← 招贤纳士单页
│   │   └── index.md
│   ├── contact/             ← 联系我们单页
│   │   └── index.md
│   ├── en/                  ← 英文版（结构与上面平行，文章保持中文不翻译）
│   │   ├── index.md
│   │   ├── about/{index,intro,teacher,honors}.md
│   │   ├── join/index.md
│   │   └── contact/index.md
│   └── images/              ← 所有图片统一放这里
│       ├── posts/           ← 文章配图，每篇动态建一个以「别名」命名的子文件夹
│       │   ├── haonian/01.jpg  02.jpg ……
│       │   └── guozui-yidui/01.jpg 02.jpg
│       ├── logo.webp        ← 校徽 / Logo
│       └── join-poster.webp ← 招新海报
│
├── themes/yckc/             ← 网站外观（主题），一般不用动
├── _config.yml              ← 站点全局配置（标题、导航等）
├── build.js                 ← 构建脚本（Vercel 部署时自动运行）
├── vercel.json              ← Vercel 部署配置
└── package.json             ← 依赖声明
```

**三个核心概念：**
| 内容类型 | 放在哪里 | 举例 |
|---------|---------|------|
| 社团动态（新闻） | `source/_posts/` 下每篇一个 `.md` | `2026-05-18-haonian.md` |
| 固定栏目单页 | `source/about/`、`source/join/`、`source/contact/` | `about/intro.md` |
| 图片 | `source/images/` 下对应子文件夹 | `source/images/posts/haonian/01.jpg` |

## 二、如何发布一篇新的「社团动态」

以「2026 年 9 月 1 日 发布一条科技节新闻」为例，全程只需 3 步。

### 第 1 步：新建文章文件

在 `source/_posts/` 目录下，新建一个文件，命名规则：

```
<日期>-<英文别名>.md
```

- 日期格式：`YYYY-MM-DD`（建议与文章实际发布日期一致，它决定网址和排序）
- 英文别名（slug）：只用**小写字母、数字、短横线 `-`**，不要用中文、空格
  - ✅ `2026-09-01-kejijie`
  - ❌ `2026-09-01-科技节.md`

> 命名后的网址会是：`/2026/09/01/kejijie/`

### 第 2 步：填入「文件头」+ 正文

打开新建的文件，最上方是一段用 `---` 包裹的**文件头（front-matter）**，下面是正文。
直接复制下面这个模板，按需修改：

```markdown
---
title: 第26届科技节圆满落幕，科创社斩获多项佳绩
date: 2026-09-01
tags: [科技节, 校园活动]
link: https://www.ycyz.com/xxxxx.html
---

这里是新闻正文，用普通 Markdown 语法写即可。

![开幕式现场](/images/posts/kejijie/01.jpg)

9月1日，我校第26届科技节在体育馆隆重举行。科创社带来了机器人、人工智能、3D打印等**多个互动展区**，吸引了全校师生驻足体验。

![学生体验机器人](/images/posts/kejijie/02.jpg)

本次科技节中，社团成员共获得一等奖 3 项、二等奖 5 项，创历年最好成绩。
```

**文件头字段说明：**

| 字段 | 必填 | 说明 |
|------|------|------|
| `title` | ✅ | 文章标题，会显示在列表和详情页顶部 |
| `date` | ✅ | 发布日期 `YYYY-MM-DD`，决定网址与排序 |
| `tags` | 可选 | 标签，用中括号包裹、逗号分隔，如 `[科技节, 校园活动]`；用于标签页归类 |
| `link` | 可选 | 若这篇动态**转载自校外新闻**（如校官网、湖北日报），填原文链接；
这里填了链接，详情页会优先跳转原文；**自己原创的文章不用填这一行** |

### 第 3 步：放图片

1. 在 `source/images/posts/` 下，建一个**与文章别名同名**的文件夹：
   `source/images/posts/kejijie/`
2. 把图片（建议 `.jpg` 即可，单张控制在 500KB 以内）放进去，按顺序命名 `01.jpg`、`02.jpg`……
3. 在正文里这样引用（路径以 `/images/posts/` 开头，斜杠别漏）：

```markdown
![图片说明文字](/images/posts/kejijie/01.jpg)
```

> 一张图占一行，前面不需要缩进。`![]()` 里中括号是「替代文字」（图片加载不出时显示，也利于无障碍），小括号是图片路径。

## 三、Markdown 写作格式速查

文章正文就是普通 Markdown，下面是最常用的几种写法：

### 1. 标题
```markdown
## 二级标题
### 三级标题
```
（文章详情页最顶部已经自动显示了 `title`，正文里一般从 `##` 开始用。）

### 2. 加粗 / 强调
```markdown
这是 **加粗** 的文字，这是 *斜体* 的文字。
```
⚠️ 注意：加粗符号 `**` 要紧贴文字，中间**不要夹空格或中文引号**，否则可能不生效：
- ✅ `**一等奖**`
- ❌ `** 一等奖 **`

### 3. 图片
```markdown
![说明文字](/images/posts/kejijie/01.jpg)
```

### 4. 链接
```markdown
详见[宜昌一中官网](https://www.ycyz.com/)。
```

### 5. 列表
```markdown
- 机器人展区
- 人工智能展区
- 3D 打印展区

1. 报名
2. 面试
3. 录取
```

### 6. 引用
```markdown
> 自我教育，终身发展。
```

### 7. 换行 / 分段
- 段落之间**空一行**即分段；
- 同一段内想换行，在行尾加**两个空格**再回车。

## 四、如何编辑已有文章

直接打开 `source/_posts/` 里对应的 `.md` 文件修改即可：
- 改 `title` / `date` / `tags` → 改文件头；
- 改内容 → 改正文；
- 换图 → 把新图放进对应的 `source/images/posts/<别名>/` 文件夹，改正文里的路径。

改完保存，`git push` 后即更新上线（见第六节）。

> 删除一篇文章：直接删除对应的 `.md` 文件（以及它专属的图片文件夹）即可。

## 五、本地预览（发布前先看效果）

在仓库根目录执行下面两条命令：

```bash
node build.js          # 第 1 步：把 md 生成网站文件，输出到 public/
npx serve public -l 4000   # 第 2 步：本地起一个预览服务
```

然后浏览器打开 `http://localhost:4000/` 即可看到效果。
确认无误后再推送上线。

> 想停止预览：在终端按 `Ctrl + C`。

## 六、发布上线（部署）

本站通过 **Vercel** 自动部署，你**不需要手动上传网站文件**，只需把源码推上去：

```bash
git add -A
git commit -m "新增科技节动态"
git push
```

推送后 Vercel 会自动执行 `node build.js` 并上线，通常 1 分钟内生效。

## 七、常见问题（FAQ）

**Q：文章发布后网页上没显示 / 404？**
- 检查文件名日期格式是否为 `YYYY-MM-DD-别名.md`；
- 检查 `date` 字段是否写对了；
- 确认文件确实放在 `source/_posts/` 下，而不是别的地方。

**Q：图片显示不出来（裂图）？**
- 路径必须以 `/images/posts/<别名>/` 开头，且**以斜杠 `/` 开头**（表示从网站根目录找）；
- 确认图片确实放在了 `source/images/posts/<别名>/` 文件夹里，文件名大小写一致；
- 文件格式建议用 `.jpg` / `.png` / `.webp`。

**Q：能不能不改代码就改导航菜单 / 页脚？**
- 导航菜单在 `_config.yml` 的 `nav` 项里配置；
- 友情链接、社长联系方式在 `_config.yml` 的 `links` / `president` 项里配置。
- 这些属于「配置」而非「内容」，改动前建议先备份或询问维护者。

**Q：英文版怎么发文章？**
- 英文版（`source/en/`）的**文章保持中文，不翻译**，因此新的社团动态只需在 `source/_posts/` 发中文即可，不会自动同步到英文站。
- 英文站目前只有栏目介绍页（概况/简介/教师/荣誉/招新/联系），如需在英文站也展示某篇动态，请联系维护者。

---

📌 **一句话总结**：写动态 = 在 `source/_posts/` 新建 `<日期>-<别名>.md` → 填文件头 → 写正文 → 图片放 `source/images/posts/<别名>/` → `git push`。
